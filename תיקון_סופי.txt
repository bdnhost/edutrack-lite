🎯 מצאתי את הבעיה האמיתית!

הבעיה:
--------
השרת החזיר:
{
  "success": true,
  "data": {
    "authenticated": true,  ← כאן!
    "user": {...}
  }
}

אבל הקוד JavaScript חיפש:
response.authenticated  ← לא response.data.authenticated

═══════════════════════════════════════════════════════

✅ מה תיקנתי:

1. api/auth.php - הפונקציה checkAuth() עכשיו מחזירה:
   {
     "authenticated": true,
     "user": {...}
   }
   ישירות, בלי עטיפת "data"

2. js/main.js - הפונקציה requireAuth() עכשיו תומכת בשני הפורמטים

3. login.html - הפונקציה checkAuth() עכשיו תומכת בשני הפורמטים

4. api/config.php - תיקנתי את נתיב הקוקי ל-'/edutrack-lite/'
